# Password_Geneartor
# 🔐 Password Generator & Strength Analyzer

A simple password generator project built using HTML, CSS, JavaScript and Python.

## Features

- Generate random passwords
- Select password length
- Include uppercase letters
- Include lowercase letters
- Include numbers
- Include special characters
- Copy password to clipboard
- Password strength indicator
- Responsive and animated interface
- Python implementation using the `secrets` module

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Python 3
